# NGS Variant Calling Pipeline

# Project Overview

This project is an automated NGS (Next Generation Sequencing) variant analysis pipeline developed using Python.

The pipeline processes FASTQ sequencing data through multiple stages including quality analysis, adapter trimming, alignment, variant calling, variant filtering, annotation and report generation.

# Features

* FASTQ File Processing
* Read Quality Analysis
* Adapter Trimming
* Reference Genome Alignment
* Variant Calling
* Variant Filtering
* Variant Annotation
* Automated Excel Report Generation

# Technologies Used

* Python
* Biopython
* Pandas
* Matplotlib
* OpenPyXL

# Pipeline Workflow

FASTQ Input → Quality Analysis → Adapter Trimming → Alignment → Variant Calling → Variant Filtering → Variant Annotation → Excel Report

# Output Files

* fastq_summary.csv
* quality_report.csv
* alignment_results.csv
* variants.csv
* filtered_variants.csv
* annotated_variants.csv
* NGS_Variant_Analysis_Report.xlsx
